# Execution consolidation assurance

This directory carries the immutable baseline, material-finding lineage, and independently derived closure evidence for the consolidation that makes Lattice the sole subscription-model execution authority.

`baseline.json` freezes the pre-implementation repositories, working implementations, installed runtime, and verified recovery snapshot. `findings.json` preserves the systemic split-authority defect at its original significance throughout remediation. [`../../ops/verify_execution_consolidation.py`](../../ops/verify_execution_consolidation.py) derives closure from base rows and bytes rather than producer status; its canonical report is written here only after installed-runtime qualification, consumer canaries, historical-journal reconciliation, credential-canary scanning, and adversarial verification all pass.
