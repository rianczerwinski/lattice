# assurance/

Frozen inputs and finding-to-proof obligations for the installed Lattice remediation generations.

```text
├── baseline.json    Pre-implementation revisions, source hashes, runtime versions, and initial checks
├── findings.json    Last installed finding → implementation → oracle → false-mutation closure ledger
└── history/         Immutable prior ledger generations
```
